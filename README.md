# HetrickCV GPL

## Phasor Beat Map

![Phasor Beat Map](PhasorBeatMap.png)

Phasor-based version of Topograph by Valley Audio. This module is a port of Mutable Instruments' excellent Grids module. 

## Phasor to Wavetable

Phasor-based version of VCV's Wavetable LFO and VCO.
